# Omar Antar — Portfolio (v2)

Personal portfolio built with [Next.js](https://nextjs.org) (App Router), TypeScript and [Tailwind CSS](https://tailwindcss.com).

> Looking for the original Create React App version? See the [`v1.0.0`](https://github.com/omarantar7/Portfolio/tree/v1.0.0) tag.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description                   |
| --------------- | ----------------------------- |
| `npm run dev`   | Start the dev server          |
| `npm run build` | Production build              |
| `npm run start` | Serve the production build    |
| `npm run lint`  | Lint with ESLint              |

## Deployment

Deployed on [Vercel](https://vercel.com) — import the repository and Vercel auto-detects Next.js; no extra configuration needed.
